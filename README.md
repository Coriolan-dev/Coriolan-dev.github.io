# Coriolan Pinhas — Portfolio

Personal portfolio for Coriolan Pinhas, published with GitHub Pages.

## Local preview

```sh
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Checks

```sh
node --test
prek run --all-files
```

The site is dependency-free: semantic HTML, CSS, and no client-side framework.
